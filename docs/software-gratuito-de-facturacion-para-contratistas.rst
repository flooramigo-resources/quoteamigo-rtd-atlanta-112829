Software gratuito de facturacion para contratistas
==================================================

QuoteAmigo ofrece a los contratistas un flujo gratuito desde la cotizacion hasta la factura. Crea una factura desde el trabajo aprobado o comienza una factura independiente, agrega monto, vencimiento e instrucciones de pago, enviala y controla su estado. El cliente paga directamente al contratista.
